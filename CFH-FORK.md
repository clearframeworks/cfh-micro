# CFH Text

CFH Text is a community fork of Micro, the terminal text editor. It adds `-cfh-inspect FILE...`, which prints each file's SHA-256 and byte count without opening it in the editor. A hash is an identifier, not a malware scan or a safety guarantee.

Upstream: https://github.com/micro-editor/micro
Base: Micro v2.0.15, commit 6a62575bcfdf4965f187eedafceb3400316e612b
